## 摘要
空间转录组学（ST）能够在空间背景下刻画基因表达，但成本仍然较高，这推动了从H&E图像推断基因表达的模型研究。现有方法面临三个关键局限：(i) 单一图像块嵌入往往不足：形态学上相似区域可能因空间背景而表现出不同表达，而朴素邻域聚合会过度平滑边界；(ii) 传统固定的基因索引输出头独立处理基因，无法直接支持对未见基因的严格零样本预测；(iii) 常用指标对空间模式保真度和边界分辨率的度量不足。为解决这些挑战，我们提出TIGEM，一种用于组织学到ST推断的拓扑信息引导、基因条件化框架。TIGEM通过利用组织级拓扑和形态学线索正则化图注意力来学习拓扑感知的spot表示，以避免跨区室平滑，并使用基因语义调制替代基因索引输出头，从而实现对未见基因的零样本预测。我们还引入图谱相关性（Graph Spectral Correlation, GSC），作为PCC/MSE的补充，用于评估空间模式保真度和边界分辨率。在三个大规模ST数据集上，TIGEM取得总体最先进的性能，并显著提升边界预测分辨率；它还进一步展示了预测训练期间未见基因表达模式的能力，通过拓扑感知空间传播和基于PLM的基因条件化扩展了此前的零样本组织学到ST工作。

## Abstract
Spatial transcriptomics (ST) profiles gene expression with spatial context but remains costly, motivating models that infer expression from H&E images. Existing approaches face three key limitations: (i) a single patch embedding is often insufficient: morphologically similar regions can exhibit distinct expression due to spatial context, while naive neighborhood aggregation can over-smooth boundaries; (ii) conventional fixed, gene-indexed output heads treat genes independently and cannot directly support strict zero-shot prediction for unseen genes; and (iii) common metrics under-measure spatial pattern fidelity and boundary resolution. To address these challenges, we propose TIGEM, a topology-informed, gene-conditioned framework for histology-to-ST inference. TIGEM learns topology-aware spot representations by regularizing graph attention with tissue-level topology and morphology cues to avoid cross-compartment smoothing, and uses gene semantic modulation to replace gene-indexed heads, enabling zero-shot prediction for unseen genes. We also introduce Graph Spectral Correlation (GSC) to evaluate spatial pattern fidelity and boundary resolution complement to PCC/MSE. Across three large-scale ST datasets, TIGEM achieves overall state-of-the-art performance and significantly improved boundary prediction resolution, and further demonstrates the ability to predict expression patterns for genes unseen during training, extending prior zero-shot histology-to-ST efforts with topology-aware spatial propagation and PLM-based gene conditioning.

# TIGEM 论文结构化总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：空间转录组学（ST）能够在保留组织空间结构的前提下测量基因表达，但成本高、操作复杂，限制了临床部署。H&E 染色全切片图像（WSI）廉价且常规可得，因此“从组织学图像推断空间基因表达”成为重要方向。
- **核心问题**：现有 histology-to-ST 方法存在三大局限：
  - **(i) 单一 patch 嵌入不足**：形态相似区域可能因空间上下文不同而具有截然不同的表达；朴素邻域聚合会把不同组织区室混在一起，导致边界处过平滑。
  - **(ii) 基因索引输出头的刚性**：传统方法使用大小为 |G_train| 的固定输出头，每个基因独立建模，无法在严格零样本设定（G_test ∩ G_train = ∅）下预测未见基因。
  - **(iii) 评价指标不足**：PCC/MSE 主要衡量逐点数值一致性，忽视空间模式保真度与边界分辨率，无法惩罚“过度平滑但 PCC 高”的预测。
- **整体含义**：论文主张缺失的不是更强的回归器，而是**上下文感知的传播规则**（信息在组织平面何处可合理传播）与**基因语义条件化**，并配套能衡量空间模式的评价指标。

## 2. 方法论（核心思想与关键技术细节）

### 2.1 总体框架
TIGEM 由两个主模块组成：
- **TIG（Topology-Informed Graph Attention）模块**：学习边界感知的 spot 表示；
- **GSMu（Gene Semantic Modulation unit）模块**：以基因语义嵌入替代基因索引头，实现零样本预测。

### 2.2 TIG 模块
- **连续屏障场（barrier field）**：
  - 构造融合形态与拓扑的稠密特征图 `F = [F_morph ∥ F_topo]`；
  - 形态通道：将 spot 嵌入投影到低维空间并用高斯 splatting 栅格化；
  - 拓扑通道：用 CellViT 做细胞分割，提取**密度图（KDE）、局部细胞核计数、各向异性/结构图**三通道；
  - 轻量 U-Net 预测非负屏障图 `B`，值越大表示越不可能传播。
- **遍历代价**：对边 (i,j)，沿线段采样 T 个点，计算 `c_ij = ‖s_i−s_j‖₂/T · Σ B(ℓ_ij(τ_t))`。
- **弱监督训练屏障场**：基于形态/拓扑差异的分位数阈值构造正边 P（同区室）与负边 N（跨边界），使用 margin ranking loss：
  `L_field = mean_{(i,j)∈P} mean_{(i,k)∈N(i)} max(0, m + c_ij − c_ik)`。
- **拓扑先验分布**：`q_ij = softmax_{j∈N(i)}(−c_ij/τ_b)`。
- **拓扑信息引导图注意力**：
  - 标准多头 GATv2，邻域为 Visium 6 个六边形邻居；
  - 通过 KL 散度将 GAT 注意力分布对齐到屏障场诱导分布：
    `L_topo = (1/L) Σ_l (1/N) Σ_i KL(stopgrad(q_i) ∥ p̄_i^(l))`；
  - **关键设计**：对 q 停止梯度，只更新 GAT 编码器，防止屏障场退化为迎合注意力。
- 每个 TIG block 含残差、LayerNorm、FFN；堆叠 L=3 个 block。

### 2.3 GSMu 模块
- 用 **ESM2 蛋白质语言模型**生成基因嵌入 `e_g`；
- 基因 token 作为 query，节点嵌入 H 作为 key/value 做**交叉注意力**，得到形态感知的基因表示 `z_g^gene`；
- 通过小型 MLP 生成 **FiLM 参数 (γ_g, β_g)**，对节点特征做通道级调制：`h̃_{i,g} = γ_g ⊙ h_i + β_g`；
- 共享 readout MLP 输出预测 `ŷ_{i,g}`，输出层不再含基因索引参数；
- **零样本**：测试时直接换入未见基因的 ESM2 嵌入，复用交叉注意力与 FiLM 读出，无需重训。

### 2.4 训练目标
`L = L_MSE + λ_topo · L_topo`。

### 2.5 新评价指标 GSC
- 构造归一化图拉普拉斯 `L = I − D^{−1/2}AD^{−1/2}`，取特征基 `U`；
- 保留累计谱能量占比 p 的截断谱系数，计算预测与真值的余弦相似度：
  `GSC(p) = ⟨x̂_true^(p), x̂_pred^(p)⟩ / (‖x̂_true^(p)‖₂‖x̂_pred^(p)‖₂ + ε)`；
- 主结果报告 **GSC@90%**；
- 论文给出数学证明：`K = U_k U_k^T` 非对角，因此 GSC 引入跨 spot 加权，能捕捉大尺度边界/区域结构，弥补 PCC 的逐点等权缺陷。

## 7. 局限与不足

- **零样本性能不均衡**：HEART 上零样本明显弱于 COAD/MEND，说明 PLM 语义迁移依赖训练基因与测试基因的功能相关性；当未见基因与训练基因语义距离较远时，ESM2 嵌入的判别力有限。
- **依赖外部组件**：拓扑通道依赖 CellViT 细胞分割，屏障场质量受分割精度影响；基因嵌入依赖 ESM2，二者均引入额外前置成本与误差传播。
- **平台与分辨率限定**：实验仅覆盖 10X Visium（55 μm spot、6 邻域），方法向高分辨率平台（如 Xenium、CosMx 单细胞级）或非六边形邻域图的迁移尚未验证。
- **评价指标仍不完美**：GSC 依赖图拉普拉斯谱截断，p 的选取带有一定主观性；SSIM 与 GSC 虽互补，但缺乏与病理学家判读直接对齐的定量生物学指标。
- **基线公平性受限**：Stem 等重型基线因算力限制可能未充分调参；零样本对比仅与 SGN 一个方法直接比较，外部有效性有限。
- **生物标志物评估以定性为主**：缺乏区域级定量指标（如边界 F1、区域 IoU）来客观衡量空间模式还原程度。
