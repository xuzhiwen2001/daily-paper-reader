ABSTRACT 

Cellular responses to perturbations vary across multiple experimental variables, such as perturbation identity, cell type, donor, and dose, defining a multidimen-sional condition space in which each measured population occupies one coordi-nate. Existing methods predict unmeasured conditions using explicit representa-tions of these variable values, generalizing unseen values therefore depends on the availability and quality of such representations. We present RELAY , a relational in-context model that predicts unmeasured coordinates from measured responses at related coordinates. For each target, RELAY uses measured control–perturbed pairs from conditions that share one or more experimental variables with the tar-get, such as the same perturbation in another cell type. The model receives only which variables are shared, not their values, and uses these demonstrations to pre-dict the target response. We evaluate RELAY on chemical, genetic, and cytokine perturbation datasets under two settings: unseen combinations , where test values are individually observed during training but not in their target combinations, and 

unseen variable values , where test values are introduced only through context at inference. RELAY outperforms existing in-context methods on unseen variable values and supervised perturbation-prediction methods on unseen combinations. All resources will be open sourced 12 , including code and data. 

1 INTRODUCTION 

Accurately predicting cellular responses to perturbations at scale has the potential to reshape target discovery and therapeutic development (Bunne et al., 2024; Rood et al., 2024; Ji et al., 2021; Qi & Chapfuwa, 2026; Dibaeinia et al., 2026). These responses are jointly determined by multiple ex-perimental variables: perturbation identity, such as a compound, cytokine, or genetic intervention; perturbation parameters, such as dose, strength, or duration; and biological context, including cell type, donor, and tissue. These factors define a multidimensional condition space in which each ex-perimentally measured cell population occupies a single coordinate, and the space grows multiplica-tively in the number of variables, so only a small fraction of it can ever be measured. Perturbation prediction is therefore fundamentally a problem of predicting responses at unmeasured coordinates from measurements elsewhere in this space. Existing methods predict at a new coordinate by conditioning on the values of its variables. Perturba-tions may be represented by learned identifier embeddings, molecular structures, gene embeddings, or knowledge-graph features, while biological covariates are commonly encoded using categorical or learned representations (Lotfollahi et al., 2019; 2023; Roohani et al., 2024; Feng et al., 2026; Guo et al., 2026; Jiang et al., 2026). This paradigm works naturally when the relevant values and representations are available during training, but becomes more restrictive for unseen values.

Learned identifier embeddings cannot represent values absent from training, while descriptor-based approaches rely on external priors whose coverage and relevance vary across variable types. More-over, many experimental variables, such as donor identity or study-specific biological covariates, lack standardized descriptors (Kedzierska et al., 2025; Ahlmann-Eltze et al., 2025; Wu et al., 2026). Thus, generalization to unseen conditions often depends on how well each variable value can be represented. Measured cell populations provide another way to specify a condition: through demonstrations of how cells actually respond, rather than through a predefined representation of the condition itself. Recent work shows that such in-context prediction is viable in single-cell biology. S TACK (Dong et al., 2026) applies tabular attention over cell sets so that one population specifies a condition ap-plied to another; SC GEN (Lotfollahi et al., 2019) transfers perturbation-induced shifts estimated from measured control and perturbed populations across cell types in a variational latent space; and general-purpose tabular foundation models with no biological pre-training are competitive with spe-cialized architectures on several perturbation benchmarks (Palla et al., 2026; Hollmann et al., 2025; Qu et al., 2025; Zhu et al., 2025). These results suggest that measured responses can serve as infor-mative conditioning signals for perturbation prediction. However, existing approaches largely treat context experiments as generic observations, without explicitly representing how each experiment is related to the target condition. This relation is informative because different context experiments reveal different components of the target coordinate. An experiment sharing the target perturbation shows how that perturbation acts in another biological context, whereas one sharing the target cell type shows how that cellular context responds to another perturbation.

For a target coordi-nate, RELAY receives measured control–perturbed pairs from con-ditions that share one or more variable values with the target, to-gether with their shared-variable relations. Variable values are used only to identify matching demonstrations and are never encoded as model inputs. We implement this formulation with a shared pair en-coder for control–perturbed population pairs, relation embeddings that encode which variables each demonstration shares with the tar-get, and target-to-context cross-attention that predicts expression changes in target control cells. The formulation extends naturally to multiple experimental variables by representing each demonstration according to the subset of variables it shares with the target. We partition the condition space into base, context, and test regions (Figure 1), and evaluate two complementary settings. Setting 1: unseen combinations. Training uses both base and context con-ditions, so the values defining a test condition have been observed individually, but their combination has not. Setting 2: unseen vari-able values. Training uses only base conditions, so every value defining a test condition is unseen during training and is introduced only through context demonstrations at inference, with model pa-rameters fixed. The first tests compositional generalization across previously observed values, whereas the second tests adaptation to entirely new variable values through inference-time evidence, with-out learning value-specific representations. Our contributions are as follows. • A relational formulation of perturbation prediction as in-context inference over a multidimen-sional condition space, using measured control–perturbed pairs that share variables with the target rather than explicit value representations. • A unified in-context model that encodes control–perturbed pairs, represents their shared-variable relations to the target, and predicts target responses through cross-attention. • An evaluation framework separating generalization to unseen combinations from generalization to unseen variable values, showing that RELAY improves perturbation-response prediction over supervised and in-context baselines under their respective settings. 2

2 RELATED WORK 

Cellular perturbation prediction. Existing methods for cellular perturbation prediction span sev-eral modeling paradigms. Early approaches model perturbation effects in latent spaces or through compositional representations of perturbations and biological covariates (Lotfollahi et al., 2019; 2023). Other methods incorporate gene-level, molecular, or mechanistic priors to support general-ization across perturbations (Roohani et al., 2024; Feng et al., 2026; Guo et al., 2026; Shi et al., 2026). More recent work models perturbation responses at the population level using optimal trans-port, flow matching, diffusion, or related distributional objectives (Bunne et al., 2023; Adduri et al., 2026; Klein et al., 2025; Yuan et al., 2026; He et al., 2026; Yu et al., 2026; Wang et al., 2026; Chen et al., 2026; Chi et al., 2026; Liu et al., 2026). Despite differences in architecture and training objec-tive, these methods typically predict a target condition by conditioning on explicit representations of its perturbation and biological covariates. 

Context-based perturbation prediction. A complementary line of work uses measured cellular re-sponses themselves as conditioning information. scGen transfers perturbation-induced latent shifts estimated from observed control and perturbed populations across cellular contexts (Lotfollahi et al., 2019). STACK (Dong et al., 2026) uses observed cell populations as in-context examples, while MapPFN (Sextro et al., 2026) and PerturbMap (Cui et al., 2026) leverage interventional observa-tions or cross-context response transfer. General-purpose tabular foundation models likewise show that inference from context examples can be competitive on cellular perturbation benchmarks (Holl-mann et al., 2025; Qu et al., 2025; Palla et al., 2026). These approaches demonstrate that measured responses can provide informative inference-time evidence. RELAY differs in explicitly represent-ing how each demonstration is related to the prediction target: each control–perturbed population pair is encoded together with the subset of experimental variables it shares with the target, while the variable values themselves are never provided to the model.

4 EXPERIMENTS AND RESULTS 

4.1 EXPERIMENTAL SETUP 

Benchmarks. We evaluate four benchmarks spanning chemical, genetic, and cytokine perturba-tions. Tahoe-100M (Zhang et al., 2025) varies compound and cell line, using 5 μM dose and matched DMSO controls. Replogle–Nadig (Replogle et al., 2022; Nadig et al., 2024) varies CRISPRi target and cell line, with non-targeting guides as controls. From the Parse cytokine dataset (Oesinghaus et al., 2025), PBMC-2D varies cytokine and cell type within Donor9, while PBMC-3D additionally varies donor; both use matched PBS controls. Dataset sizes and condition-level cell counts are summarized in Appendix A.1. 

Evaluation protocol. We follow the partitions and settings defined in Section 3.1. Setting 1 trains on base and context conditions to predict unseen combinations, whereas Setting 2 trains only on base conditions and introduces context at inference without parameter updates. Both settings use the same test conditions and inference context. On Tahoe-100M, base and held-out compounds are additionally separated by Bemis–Murcko scaffold (Bemis & Murcko, 1996). All methods use iden-tical data splits and preprocessing, including library-size normalization to 10 4, log transformation, and a common highly variable gene panel selected using training-visible cells only. Split construc-tion and preprocessing are detailed in Appendices A and B.1, respectively. 

Baselines. We evaluate broadly applicable baselines across chemical, genetic, and cytokine pertur-bation benchmarks. Setting 1 includes five supervised methods: STATE (Adduri et al., 2026) mod-els perturbation responses at the population level. CellFlow (Klein et al., 2025) learns covariate-conditioned transport maps from control to perturbed populations. CPA (Lotfollahi et al., 2023) combines a basal cell state with perturbation and covariate embeddings. We also include two re-cent baselines: scDFM (Yu et al., 2026) generates perturbed cell distributions from control states and perturbation embeddings via conditional flow matching with an MMD objective. PerturbDiff 

(Yuan et al., 2026) models perturbation responses through functional diffusion over cell-population distributions embedded in a Hilbert space. Setting 2 includes three context-based methods: STACK (Dong et al., 2026) uses attention over mea-sured cell populations to predict responses in a target population. TabPFN (Hollmann et al., 2025; Palla et al., 2026) uses a pretrained tabular model to infer target responses from context examples. 

scGen (Lotfollahi et al., 2019) is adapted to transfer perturbation-induced latent shifts from context populations to target controls. Both settings also include two non-learning baselines: Untreated

Metrics. We evaluate expression accuracy and perturbation-response recovery, averaging each met-ric equally over test conditions. MSE and MAE measure differences between predicted and ob-served mean expression profiles. PDCorr measures Pearson correlation coefficient between pre-dicted and ground-truth relative perturbation effects. PDS measures perturbation specificity by ranking the correct measured response against other perturbations sharing the same non-perturbation variables. REACH is based on differential expression (DE) analysis and measures the fraction of reference DE genes recovered with reliable response directions, prioritizing genes with stronger pre-dicted statistical evidence (Welch, 1947; Benjamini & Hochberg, 1995). Lower MSE and MAE and higher PDCorr, PDS, and REACH indicate better performance. Formal definitions of the training objective and evaluation metrics are provided in Appendix B.3. 4.2 MAIN RESULTS 

Tables 1 and 2 summarize performance in the two evaluation settings. We report means and standard deviations over three seeds. 

Setting 1: unseen combinations. RELAY achieves the highest PDCorr and lowest MSE on all four benchmarks, while also outperforming all supervised baselines in PDS. The largest absolute PDCorr margin over the strongest supervised baseline occurs on PBMC-3D, where RELAY reaches 0.495 compared with 0.225 for STATE, highlighting its effectiveness in a condition space span-ning perturbation, cell type, and donor. Beyond these consistent gains, RELAY also achieves the highest REACH on Tahoe-100M and Replogle–Nadig, supporting its ability to recover differential-expression response directions. These results show that relational context supports generalization to unobserved combinations of previously seen variable values, improving both perturbation-effect recovery and mean expression accuracy. 

Setting 2: unseen variable values. RELAY outperforms the learned context-based baselines STACK, scGen, and TabPFN in PDCorr, PDS, and REACH on all four benchmarks. The largest PDCorr margin occurs on Tahoe-100M, where RELAY reaches 0.467 compared with 0.268 for sc-Gen. Performance is generally lower than in Setting 1 when the target variable values are entirely absent from training, reflecting the greater difficulty of inference from context alone. Simple base-lines nevertheless remain competitive on some metrics: Mean perturbation achieves the highest PDS on the three 2D benchmarks, while Untreated obtains lower MSE and MAE than RELAY on Replogle–Nadig and PBMC-3D despite near-zero PDCorr. This contrast highlights that low absolute expression error does not necessarily imply accurate recovery of perturbation effects. 4.3 ABLATION AND MODEL ANALYSIS

Random context replacement. To test whether the model relies on the correspondence between the provided context and the target condition, we replace demonstrations at inference while keeping the target controls, context size, and group sizes unchanged (Figure 4b). Random replacement preserves each control–perturbed pair but leaves the original relation embeddings unchanged, disrupting the correspondence between demonstrations and the target. All three metrics decrease monotonically with the replacement fraction: PDCorr falls from 0.495 to 0.071, PDS from 0.833 to 0.504, and REACH from 0.420 to 0.048. These results confirm that the model is sensitive to the correspondence between demonstrations and the target condition. 

Borrowed context replacement. Borrowing the complete context of another target also lowers all three metrics for every tested overlap pattern. Sharing both perturbation and donor best preserves all three metrics among these replacements, reaching PDCorr 0.424, PDS 0.807, and REACH 0.238, but still does not recover matched-context performance (Figure 4c). Together with random replacement, these results show that RELAY retains useful predictive signal under partially noisy or mismatched context, while accurate target-specific demonstration selection remains important. 

Attention to context. We examine which context populations receive more attention from target control cells, with each context group containing 5 demonstrations (Figure 5). In PBMC-2D, atten-tion favors control-origin tokens in demonstrations sharing the target cell type, but perturbed-origin tokens in those sharing the target perturbation. PBMC-3D shows a similar pattern: demonstrations sharing both cell type and donor receive more attention on control-origin tokens, whereas those shar-ing perturbation alone or perturbation and donor receive more attention on perturbed-origin tokens. Thus, the relative attention to the two populations within a pair varies with the variables shared between the demonstration and the target. In PBMC-3D, two-variable matches also receive more attention than single-variable matches despite equal group sizes, consistent with the larger perfor-mance drops observed when two-variable matches are removed. These observations describe how attention is distributed, rather than establish which demonstrations cause better predictions. More-over, control- and perturbed-origin tokens are not independent representations of the two states, as pair self-attention allows them to exchange information.

A.2 SPLIT CONSTRUCTION AND BALANCE 

Binning strategy. We rank variable values by their treated-cell counts and divide them into bins containing nearly equal numbers of values, then sample held-out values within each bin. All four datasets use six perturbation bins; Tahoe-100M and both PBMC datasets additionally use four cell-line or cell-type bins, and PBMC-3D uses two donor bins. Replogle–Nadig holds out approximately 20% of perturbations and one cell line (HepG2). Tahoe-100M targets a 20% holdout on both axes while keeping drug scaffold groups intact, with a penalty for deviations from the target bin alloca-tion. Both PBMC splits hold out three perturbations per bin and one cell type per bin; PBMC-3D also holds out one donor per bin. PBMC-2D searches donor-specific candidates and selects Donor9. Bins stratify sampling by abundance; entropy is computed over individual variable values or joint conditions, not over the bins.

Each cell is projected to a 512-dimensional representation. A Q-former with q = 15 learned query tokens summarizes each cell set, followed by a population-mean token. The two states in each demonstration are processed by two pair-level self-attention blocks, and target cells use four trunk cross-attention blocks to attend to the context memory. The context and target populations are sam-pled with n = 128 cells per bulk; the standard training configuration uses five context pairs for each active context group, batch size 32, and AdamW with learning rate 10 −4 and weight decay 10 −4.We use eight attention heads, a 2,048-dimensional feed-forward layer, zero dropout, and cosine learning-rate decay to a minimum of 10 −5 over 40,000 steps. Each experiment takes approximately 8 hours on a single NVIDIA A100 GPU. 15
